## Where the data comes from, and on what terms

The rows in `russia-suppliers_2015-2025.csv` were compiled from the supplier-level data behind the UN Annual Statistical Report on Procurement, which the United Nations Global Marketplace (UNGM) publishes on its website. UNGM's own Terms and Conditions (<https://www.ungm.org/Public/Pages/Terms>, section 5) permit downloads "for personal use only" and say that material from the site should not be disseminated without UNGM's prior written permission. This repository does not claim any licence from UNGM. It republishes a documented slice of public procurement statistics as journalism in the public interest, with full attribution to the source and with the caveats stated above, in the same way that procurement data from TED, the World Bank and IATI is routinely republished.

The CC BY 4.0 licence above therefore covers what is ours — the selection, checking, documentation and manifest — and not the underlying facts, which remain the UN's own published reporting. Anyone reusing the file should keep the source attribution and is encouraged to read UNGM's terms for themselves.

If you represent UNGM or a UN entity and object to this publication, write to registry.nako[at]gmail.com; the repository keeps a public history, so any change made in response will be visible.
